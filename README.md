# מחשבון — אפליקציית Android נייטיב (Kotlin)

אפליקציית מחשבון נייטיב, ללא ספריות חיצוניות, Kotlin + Android Views.
מינימום Android 8.0 (API 26), יעד Android 15 (API 35). מתאים ל-Samsung S21.

## מה יש בה
- ארבע פעולות, סוגריים חכמים `( )`, אחוזים `%`, החלפת סימן `±`
- חישוב מדויק עם BigDecimal (‏0.1+0.2 = 0.3)
- תצוגה מקדימה של התוצאה בזמן ההקלדה
- ⌫ מוחק תו, לחיצה ארוכה עליו מנקה הכול
- לחיצה ארוכה על התצוגה מעתיקה את התוצאה
- רטט קל בכל לחיצה, מצב כהה, אייקון אדפטיבי
- הקלדה נשמרת בסיבוב מסך

## בנייה
**מהטלפון (בלי מחשב):** מעלים את התיקייה ל-repository ב-GitHub. ה-workflow שב-`.github/workflows/build.yml`
בונה את האפליקציה אוטומטית ומפרסם `Calculator.apk` בעמוד ה-Releases של ה-repo.
פותחים את הקובץ בטלפון ומאשרים "התקנה ממקורות לא ידועים".

**במחשב:** פותחים את התיקייה ב-Android Studio ולוחצים Run.

## מבנה
- `app/src/main/java/com/udi/calculator/Evaluator.kt` — מנתח ומחשב ביטויים
- `app/src/main/java/com/udi/calculator/MainActivity.kt` — מסך, מקלדת ולוגיקת הקלדה
- `app/src/main/res/` — פריסה, צבעים, מחרוזות, אייקונים
