# מחשבון מדעי — בהשראת Casio fx-81 (Android נייטיב, Kotlin)

מחשבון מדעי בסגנון המחשבונים הכיסיים של שנות ה-80: מסך LCD עם ספרות 7-מקטעים,
מקש SHIFT עם פונקציות משניות (בצהוב מעל המקשים), ולוגיקה אלגברית קלאסית.

## פונקציות
- `sin cos tan` והפוכות (SHIFT), היפרבוליות (`hyp`), מצבי זווית DEG / RAD / GRA (`DRG`)
- `√` / `∛`, `x²` / `x³`, `log` / `10ˣ`, `ln` / `eˣ`, `xʸ` / `x^(1/y)`, `x⁻¹` / `x!`, `π`
- סוגריים עד 15 רמות, סדר פעולות (חזקה › כפל/חילוק › חיבור/חיסור)
- `EXP` להזנת מעריך, `±`
- זיכרון: `Min`, `M+`, `M−` (SHIFT), `MR`, `X↔M` (SHIFT) — נשמר גם אחרי סגירת האפליקציה
- תצוגה: 10 ספרות + מעריך של 2 ספרות; שגיאה מוצגת כ-`-E-` ומתנקה ב-`C` או `AC`

פונקציות כמו sin ו-√ פועלות מיד על המספר שבתצוגה: `30 sin` = 0.5.

## בנייה
כל push ל-GitHub בונה את האפליקציה ומפרסם `Calculator.apk` בעמוד ה-Releases.

## מבנה
- `Engine.kt` — מנוע החישוב (מחסנית אופרטורים, פונקציות, זיכרון, עיצוב תצוגה)
- `LcdView.kt` — מסך LCD מצויר עם ספרות 7-מקטעים
- `MainActivity.kt` — מקלדת ומיפוי מקשים
